# authenticated-with-django-cbv

A simple Django authentication system with user registration, login, logout, and protected pages using Class-Based Views (CBVs).

This beginner-friendly project demonstrates user authentication using Django's built-in authentication system.

## Features

- User registration with username, email, and password
- User login and logout
- Password validation and secure password hashing
- Protected pages for authenticated users
- Django Class-Based Views (CBVs)
- CSRF protection
- SQLite database

## Technologies Used

- Python
- Django
- HTML
- SQLite
